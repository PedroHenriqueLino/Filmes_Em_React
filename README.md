# 🎬 CineCartaz

O **CineCartaz** é uma aplicação web de filmes desenvolvida com React.  
O projeto permite explorar filmes, pesquisar títulos, filtrar por categorias, visualizar detalhes e adicionar filmes aos favoritos.

## 🚀 Tecnologias utilizadas

- React
- Vite
- React Router DOM
- Axios
- Context API
- JSON Server
- LocalStorage
- CSS
- Tabler Icons

## ✨ Funcionalidades

- 🎬 Catálogo de filmes
- 🔎 Pesquisa de filmes
- 🏷️ Filtro por categorias
- ⭐ Avaliação dos filmes
- 📖 Página de detalhes
- ❤️ Sistema de favoritos
- 💾 Salvamento dos favoritos no LocalStorage
- 👤 Configuração de perfil
- 🖼️ Escolha de avatar
- 📱 Layout responsivo
- 🎞️ Banner de filmes em destaque
